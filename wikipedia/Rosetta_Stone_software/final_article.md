# Rosetta Stone software

Rosetta Stone Language Learning is proprietary, computer-assisted language learning (CALL) software published by Rosetta Stone Inc, part of the IXL Learning family of products. The software uses images, text, and sound to teach words and grammar by spaced repetition, without translation. Rosetta Stone calls its approach Dynamic Immersion.

The software's name and logo allude to the ancient stone slab of the same name on which the Decree of Memphis is inscribed in three writing systems.

IXL Learning acquired Rosetta Stone in March 2021.

== History ==

According to the company, Allen Stoltzfus learned German by living in Germany through immersion, and he lived in Germany while learning German.

In a Rosetta Stone Language Learning exercise, the learner pairs sound or text to one of several images.
The number of images per screen varies.

For example, the software shows the learner four photographs.
A native speaker makes a statement that describes one of the photographs, and the statement is printed on the screen; the learner chooses the photograph that the speaker described.
In another variation, the learner completes a textual description of a photograph.

In writing exercises, the software provides an on-screen keyboard for the user to type characters that are not in the Latin alphabet or accents that may not be in their native language.

Grammar lessons cover grammatical tense and grammatical mood.
In grammar lessons, the program firstly shows the learner several examples of a grammatical concept, and in some levels, the word or words the learner should focus on are highlighted.
Then the learner is given a sentence with several options for a word or phrase, and the learner chooses the correct option.

If the learner has a microphone, the software will evaluate word pronunciation using the embedded speech recognition engine, TrueAccent.

Each unit contains reviews of the content in those lessons, and each unit concludes with a Milestone activity, which is a simulated conversation that covers the content of the unit.

== Core Philosophy and Methodology ==

The system uses linguistic rules in an intuitive manner, and the company states that the software is designed to teach languages as humans learn their native language.
In each lesson, the language student must choose the correct image out of four images.
Grammatical functions are learned intuitively, the software's goal is for users to learn the language they are studying intuitively, and users should learn the target language in the same way they learned their native language.
The Dynamic Immersion Method allows users to virtually experience the process of acquiring language abilities for the first time, similar to infants.
The method differs from traditional learning methods involving memorization of words and grammar, yet the goal is for learners to memorize words and grammar intuitively.
Learners do not use dictionaries in this method.
The product advertisement states that the learning method is the same as how people learn their first language, and language learning with the software occurs in the same way as a child learns their first language.

== Interactive Features and Media ==

The educational suite includes an interactive learning system that integrates sound, motion, and writing.
In the "Listen and read" section, the student reads the text while the native speaker speaks.
The product features a unique speech recognition function where the system compares the student's voice to the native speaker's voice.
One of the lesson modes is conversation, and the program uses video recordings.

== Progression and Structure ==

Difficulty levels increase as the user progresses with the software, and vocabulary is expanded over time.
Dynamic Immersion has one test stage and three interim stages.
The difficulty increases as the student progresses.

The program immediately informs the learner whether the answer is right or wrong and indicates where the errors are located.
Through the Preferences screen, the learner can choose whether a sound is played or not when an answer is clicked, choose the type of marks, and adjust the level of pronunciation perception sensitivity.
At the bottom of the window, the program shows all the screens for the current lesson.
If all answers for that screen are correct, the button for that screen turns green.
If some answers are correct, the border of the button turns green, but the screen number itself turns orange.
If all answers for a screen are wrong, the button turns orange.
This applies to all lessons except review and Milestone lessons, which are treated as tests.
In those lessons, the buttons for each screen all remain clear.
In all lessons, there is a button that can be hovered over to display how many answers are correct, incorrect, or have not been answered.
Each time an answer is clicked, one point is given, and selecting the last remaining option awards 1 point.
At the end of the lesson, the total number of correct, wrong or skipped answers is shown alongside the percentage of correct answers for that lesson, and the program evaluates answers on a scale from 0 to 100.
If too many questions were answered incorrectly, the program suggests the learner should retry the lesson.

Frequent criticism of the program arises in its lack of sensitivity to the differences between the various languages it comes in and their respective cultures. Early versions of the software presented the same concepts in the same order, using the same images taken mostly in the Washington, D.C. area near the company's headquarters at the time in Harrisonburg, Virginia. In the most recent version, there have been some modifications to the picture set for certain languages or regions.

Another frequent issue was the use of more formal vocabulary than that regularly used by native speakers. In 2006, Macworld reviewer Cyrus Farivar noted that his Persian CD used khodrow for "car", although most native speakers use a French loanword, ma:sheen (in the same way English speakers would be more likely to say "car" than "automobile" in everyday speech). The same course did not teach words that would be important to someone learning Persian, such as "bread" and "tea"; however, it very curiously included the word "elephant" in a basic vocabulary lesson. Perplexed by the question of why the word "elephant" would be taught in a language where it might never be used (there are not many elephants in Iran), Farivar called Rosetta Stone, Inc. He was told that the company makes four different picture sets: one for Western languages, another for Asian languages, and two sets unique to each Swahili and Latin. The Persian language CD was using the Western picture set, which explains why the images were not culturally relevant.

Writing in 1997, Donald McRae of Brock University said that Rosetta Stone represented "good pedagogy" and that "the authors of the program never lose sight of solid teaching methodology".
He described the Version 2 German language course as "very good", but indicated that he had "some reservations".
McRae was more favorable towards the German version a few months earlier.
McRae disagreed with a statement made by Fairfield that the program could completely replace a beginner-level language course.
McRae identified a flaw in the program where it failed to distinguish between German verbs meaning 'to run'.
A student could reasonably conclude that 'rennen' applies only to animals.

In a 1997 review of the Version 2 Russian language course, Mark Kaiser, director of the Language Media Center at the University of California, Berkeley, called the program "woefully inadequate for a number of reasons".
One of Kaiser's observations was that Rosetta Stone software fails to provide a relevant cultural context.
Because the company uses the same stock photographs for all its language courses, they depict people, activities, and manufactured goods that are conspicuously American.
Kaiser also found that Rosetta Stone Version 2 does not provide a way for students to evaluate their conversation skills, and that some of the words and phrases are too English-based.
According to Kaiser, no native Russian speaker would use the verb 'to use' in this context.
Kaiser noted that some prepositions introduced in early lessons take different endings.
"The entire package lacks any pedagogical foundation," he concluded.
"Rather, it utilizes the glitz of the multimedia capabilities of the computer, a dearth of quality foreign language software, and clever marketing to create an economically successful product."
